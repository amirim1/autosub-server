# AGENTS.md - Рабочие соглашения и правила проекта AutoSub Server

## 1) Политика создания релизов и тегов (Strict Release Policy)
- **Запрещено спамить новыми тегами:** При обнаружении ошибок или необходимости мелких доработок сразу после выкатки релиза **НЕ СОЗДАВАТЬ новый релизный тег** (например, с v1.3.1 на v1.3.2 или v1.3.3).
- **Обновление текущего тега:** Все исправления и доработки текущей версии должны вноситься в **тот же самый релизный тег** (путем обновления локального тега, force-push на GitHub и обновления соответствующего GitHub Release).
- **Гарантия качества релиза:** Каждый выпущенный релиз на GitHub должен быть полностью исправным, протестированным и рабочим.

---

## 2) Основные принципы работы
- Сначала проясните неясность: если требование неясно или неполно, задайте 1-2 уточняющих вопроса.
- Вводите только то, что было запрошено.
- Минимальное жизнеспособное изменение.
- Повторное использование перед переписыванием.
- Конфигурация и секреты: загружайте из переменных среды, избегайте жесткого кода.
- Очистка временных файлов после тестирования.
